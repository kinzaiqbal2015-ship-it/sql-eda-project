# SQL Exploratory Data Analysis Project

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) using SQL Server to explore sales data, evaluate business metrics, and analyse customer and product performance.

## Objectives
- Explore database tables and dimensions.
- Analyse customer and product information.
- Calculate key business metrics and KPIs.
- Perform magnitude analysis across different categories.
- Identify top-performing products and customers.

## Tools & Technologies
- Microsoft SQL Server
- SQL

## SQL Techniques Used
- SELECT and DISTINCT
- Aggregate Functions
- GROUP BY and ORDER BY
- MIN, MAX, SUM, AVG and COUNT
- DATEDIFF and GETDATE
- LEFT JOIN
- UNION ALL
- TOP
